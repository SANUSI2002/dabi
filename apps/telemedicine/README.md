# Sabi Health — Frontend

This is the web app (PWA) for Sabi Health. It contains:

- `packages/design-system` — shared colors, buttons, cards, and other reusable
  building blocks used across every portal (patient, doctor, hospital).
- `packages/patient-portal` — the patient-facing app (dashboard, records,
  appointments, etc.). Built first.
- Future portals (`doctor-portal`, `hospital-portal`) will be added here as
  new folders under `packages/` when work on them begins — no need to
  pre-create empty folders for sections we haven't started yet.

See `CONTRIBUTING.md` for how to branch, commit, and open pull requests.
